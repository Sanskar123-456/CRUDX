# CRUDX – MERN CRUD Application

CRUDX is a full-stack CRUD application built using the MERN stack. It demonstrates the implementation of **Create, Read, Update, and Delete** operations with a clean and responsive user interface.

## 🚀 Features

- Create new records
- View existing records
- Update records
- Delete records
- Responsive and user-friendly UI
- REST API integration
- MongoDB database integration

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3
- Tailwind CSS

### Backend
- Node.js
- Express.js
- REST API

### Database
- MongoDB
- Mongoose

### Tools
- Git & GitHub
- VS Code
- Postman
